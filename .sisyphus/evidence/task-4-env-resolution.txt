## ROOT CAUSE ANALYSIS

### The Problem
Disabling TaskRunnersConfig.enabled completely removes the executeCommand node type 
from n8n's node registry. This is because:

1. Task runners are not just an execution mode - they're the **provider** for executeCommand nodes
2. When TaskRunnersConfig.enabled = false, n8n doesn't load the executeCommand node type at all
3. The workflow can't even **activate** (let alone execute) because it contains unrecognized nodes

### Why This Approach Failed
The original issue was: "$env variables show '[not accessible via UI]' when task runners are enabled"

Our fix: Disable task runners entirely

The consequence: executeCommand nodes become completely unavailable, breaking the workflow
